# MVIKAS Logistics — Automated Executive Dispatch & Operations Dashboard

An automated, open-source, production-ready logistics command center and executive dashboard for **MVIKAS Logistics**. Features a modern dispatcher command UI inspired by freight load planning studios, live Google Sheets automation, predictive revenue tracking, and root-cause delay analytics.

Hosted completely for free on **GitHub Pages** with scheduled data synchronization powered by **GitHub Actions**.

---

## ⚡ Key Features

- **Automated Daily Pipeline (1:00 PM IST)**: GitHub Actions automatically fetches data from your Google Sheet daily at 1:00 PM IST (07:30 UTC), computes all operational statistics, and redeploys to GitHub Pages without touching any code.
- **Decoupled Architecture**: Code and data are cleanly separated (`data/latest_data.json`). No more manual prompting or copy-pasting code!
- **Modern Dispatch & Fleet UI**:
  - Interactive cargo truck visualization with compartment load planning.
  - Dispatch Transit Timeline / Gantt chart tracking order progression.
  - Executive Quick Metric Badges (+33%, +15%, -22%).
- **5 In-Depth Operational Tabs**:
  1. **Fleet & Dispatch Command**: Real-time load planning, active carrier allocation, and shipment transit Gantt timeline.
  2. **Pipeline Classification**: Total open pipeline, EDD crossed, due tomorrow, booked yesterday, customer breakdown donut, and open shipment risk table.
  3. **Tonnage & Revenue Forecast**: 10-day period selector (Full Month, First 10, Mid 10, Last 10 Days), Target vs Achieved bar chart, and KAM performance summary.
  4. **Daily Average & Pace**: Client-wise daily average pace, days needed to hit monthly targets, and pace ranking.
  5. **EDD Crossed Orders**: Filterable delay table (by search, type, transporter, reason) with 1-click **Export to Excel**.
  6. **Root-Cause Delay Analysis**: Categorized breakdown (Carrier, Customer, Documentation, External, Location, Damage), Customer vs Vendor attribution, and AI-recommended actions.
- **In-Browser Upload & Preview**: Drag-and-drop any Excel workbook directly into the dashboard for instantaneous local preview.

## 🚀 Setup & Google Sheets Automation

### Step 1: Connect your Google Sheet
1. Open your Google Sheet in Google Drive.
2. Click **Share** (top right) and set access to **"Anyone with the link can view"**.
3. Copy the URL (e.g., `https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit`).

### Step 2: Add URL to GitHub
1. Go to your repository on GitHub: `https://github.com/MVIKAS-CODE/Dashboard-Automate`.
2. Go to **Settings** → **Secrets and variables** → **Actions**.
3. Under **Repository secrets**, click **New repository secret**:
   - **Name**: `GOOGLE_SHEET_URL`
   - **Value**: Paste your copied Google Sheet link.
4. Click **Add secret**.

*(You can also set it under **Variables** if you prefer it visible to collaborators).*

### Step 3: Enable GitHub Pages
1. Go to **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
3. Choose branch: **`main`** and folder: **`/ (root)`**.
4. Click **Save**. Within 1–2 minutes, your dashboard is live at:
   `https://mvikas-code.github.io/Dashboard-Automate/`

## ⏰ How the Daily Sync Works

The automated pipeline is defined in [`.github/workflows/daily_update.yml`](.github/workflows/daily_update.yml):
- **Schedule**: Runs automatically every day at **1:00 PM IST** (`07:30 UTC`).
- **Manual 1-Click Trigger**:
  1. Go to the **Actions** tab on GitHub.
  2. Select **Daily Dashboard Data Sync & Deploy** from the left sidebar.
  3. Click **Run workflow** → **Run workflow**.

## 💻 Local Testing & Manual Update

You can also run the data update locally on your Windows machine:

```powershell
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run update with your Google Sheet URL
python scripts/update_dashboard.py --source "https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit"

# Or simply double-click:
scripts\local_update.bat
```

## 🛡️ Sheet Format Compatibility

The parser automatically detects and matches standard sheet tab names (case-insensitive and flexible):
- `Open Shipment` / `Open Shipments`
- `Order EDD Crossed` / `EDD Crossed`
- `Order due Tomorrow` / `Due Tomorrow`
- `Shipment Booked Yesterday` / `Booked Yesterday`
- `Daily Tonnage`
- `Total_Tonnage_this_month` / `Month Tonnage`
- `Tonnage_of_<Month>_Month` / `Monthly Target`
